# Third-party code

- `third_party/s7/` - s7 Scheme interpreter by Bill Schottstaedt (0-clause BSD, see `LICENSE`).
  Version 10.6, taken from a GitHub mirror of https://cm-gitlab.stanford.edu/bil/s7.
- `vlib/` - git submodule of https://github.com/BolvicBolvicovic/vlib, pinned to a commit and used unmodified (see `.gitmodules`).
- `third_party/doxygen-awesome-css/` - doxygen-awesome-css by jothepro (MIT, see `LICENSE`), version
  2.5.0 (tag `v2.5.0` of https://github.com/jothepro/doxygen-awesome-css). Only the files the
  generated API site uses, included unmodified; not part of the binaries or the library.
