# Function codes

One page per function code the simulator answers, with the request and response layout, limits, errors and examples. Type in the box to filter by name or code.

Codes are written in hexadecimal. For the list at a glance, the transports they run on and what is
left out, see [Modbus support](modbus-overview.md). The sub-functions of Diagnostics (0x08) are
listed separately in [Diagnostics sub-functions](diagnostics-subfunctions.md).
